話した動画から、テロップ付きの下書きを作る。

配布準備中

できることWHAT

IMPORT

取り込むと、下書きができる

話している動画を入れると、喋りを文字に起こし、読める長さに割ったテロップを並べます。画面が止まっている所には、話の要点をスライドにして重ねます。

EDIT

気になる所だけ手で直す

分割・削除・元に戻す、テロップの追加や文字の書き換えができます。直すたびに自動で保存され、閉じても続きから開けます。

EXPORT

そのまま書き出す

完成動画のMP4、字幕のSRT、ほかの編集ソフトへ持っていくためのFCPXMLを書き出します。直して何度でも書き出し直せます。

手で直せることEDIT

クリップの分割・削除。元に戻す／やり直し
テロップの追加と、文字の書き換え
コピー・貼り付け・複製
編集するたびに自動保存。編集ファイル（.kairos）を開けば続きから

動かす環境SPEC

MAC

Apple Silicon Mac

文字起こしは手元のMacの中で行います。動画をどこかへ送る作りにはしていません。

OUTPUT

MP4 ／ SRT ／ FCPXML

そのまま投稿できる動画と、字幕、編集ソフト向けのファイルを一緒に出します。
