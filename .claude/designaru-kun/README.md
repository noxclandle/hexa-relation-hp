# デザイナルくん（designaru-kun）

日本と海外のデザイン知識1500項目を参照して動く、Claude Code のデザイナー用サブエージェントです。

## 構成

```
.claude/
├── agents/
│   └── designaru-kun.md          # エージェントの定義（役割・進め方・ルール）
└── designaru-kun/
    ├── README.md                 # このファイル
    └── knowledge/                # 知識ベース（10分野 × 150項目 = 1500項目）
        ├── 01_principles.md            P001–P150 デザイン原則・レイアウト・UX心理
        ├── 02_typography.md            T001–T150 タイポグラフィ
        ├── 03_color.md                 C001–C150 色彩
        ├── 04_movements_styles.md      M001–M150 デザイン史・様式・トレンド
        ├── 05_japan_designers.md       J001–J150 日本のデザイナー・事例
        ├── 06_global_designers.md      G001–G150 海外のデザイナー・事例
        ├── 07_branding_ui_web.md       B001–B150 ブランディング・UI/UX・Web・SNS
        ├── 08_game_ui_retro.md         R001–R150 ゲームUI・ピクセルアート・レトロ
        ├── 09_image_photo_illustration.md  I001–I150 写真・イラスト・生成AI画像
        └── 10_video_motion.md          V001–V150 動画・モーション・映像演出
```

## 使い方

Claude Code でこのリポジトリを開き、次のように依頼します。

- 「デザイナルくんに、このLPのデザインレビューをしてもらって」
- 「デザイナルくんで、カフェのロゴ案を3つ出して」
- 「デザイナルくん、YouTubeサムネの構成とプロンプトを作って」
- 「デザイナルくん、15秒の縦型PR動画の絵コンテを作って」

`/agents` コマンドで一覧に `designaru-kun` が出ていれば利用できます。

## できること・できないこと（正確な説明）

- **できること**：知識ベース・モデル本来の知識・Web検索をもとに、企画、配色、書体の選定、レイアウト、HTML/CSSでの実装、ロゴのSVGのたたき台、写真やイラストのディレクション、動画の構成と絵コンテ、生成AI用のプロンプト作成、デザインレビューを行います。Higgsfield MCP が接続されている環境では、ユーザーの承認を得たうえで画像・動画を生成できます。
- **できないこと**：このエージェントは、モデルを画像や動画で「再学習（ファインチューニング）」したものではありません。知識ベースは画像ではなく、テキストで書いたデザイン知識1500項目です。

## 知識ベースの方針

- 広く知られた事実と、一般的に通用する原則だけを記載しています。確信のない帰属や年号は書いていません。
- プラットフォームの仕様（画像サイズ、法制度など）は変わるため、使う前に公式情報で確認するよう、エージェントに指示しています。
- 誤りを見つけた場合や項目を追加する場合は、該当ファイルを直接編集してください。IDは連番で追加します（例：`P151`）。
