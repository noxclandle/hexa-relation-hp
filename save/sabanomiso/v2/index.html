Philosophy

若手が、
呼吸できる業界へ。

建設業界の古い常識を壊して、若い人が働きやすく、福利厚生をきちんと整えた場所をつくりたい。

平均年齢が低く、しがらみのない、フラットな組織。上下関係よりも、話せる関係を。霧の中でも迷わず戻ってこられる場所を、未来の職人のために建てています。

従業員との約束

約束はひとつだけ。嘘をつかないこと。

自分が建てた枠にコンクリートを流し、脱型した瞬間に、建物の本当の形が現れる。あの瞬間の誇りのために、何ごとも妥協しない。

— さばのみそ

  3. 1–3期 / The Fog
